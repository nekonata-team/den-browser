# Use Sparkle's Scheduled Update Checks

Den Browser starts Sparkle at application launch and relies on its scheduled automatic update checks, whose default interval is 24 hours. Automatic checking does not require enabling Sparkle's separate automatic download and installation option. Den Browser does not force an additional check on every launch because the scheduled check already discovers and presents available updates without adding redundant network requests; users can still run an immediate check from **Check for Updates…**.
