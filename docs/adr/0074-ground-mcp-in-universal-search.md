# Ground Den's MCP tools in Universal Search

A catalog that mirrors the CLI makes clients choose among low-level operations before they know what the user means. Publish seven tools for overview, search and action, opening pages, reading pages and Inspection selections, and listing Notifications. Reuse Universal Search ranking and Den's existing operations. Keep detailed Sheet, Drawer, Profile, and Terminal controls in the CLI.

Den Browser owns temporary action refs so search and execution use the same Profile and target identity even if focus changes. Movement choices bind one destination, and Desk removal confirmations bind the Board list shown in the preview. The local stdio server and typed Unix-socket IPC from [ADR 0055](0055-add-den-mcp-server.md) remain in use.
