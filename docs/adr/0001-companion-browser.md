# Den Browser is a companion browser

Den Browser is a companion browser for long-running parallel web work, not a general-purpose browser replacement. This lets the product focus on desks, boards, sheets, restoration, and keyboard-driven spatial work instead of taking on the full surface area of bookmarks, extensions, default-browser behavior, and general browsing workflows.

Current Sheets support deliberate file downloads without adding Download management to the Den work model, as decided in [ADR 0027](./0027-support-deliberate-downloads-without-managing-them.md).
